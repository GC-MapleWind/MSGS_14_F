# Kangmin GitHub Pages

This directory is an independent static showcase for GitHub Pages. It does not
modify or depend on the local Svelte mockup served at `localhost:5173`.

- Character: 강민 / 마가다락방 / 에오스 / Lv. 285 / 제로
- Settlements: 12 real entries from the existing public `MSGS_13_F` archive
- Assets: locally bundled WebP copies for a backend-free Pages deployment
- Audio: omitted because the source archive contains no real audio files

Open `index.html` through an HTTP server for local verification:

```bash
python3 -m http.server 4173 --directory github-pages
```
